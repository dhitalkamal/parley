Model: clauth-style. Six full-screen tabs across the top (1-6 or left/right arrows), active tab filled orange. Each tab is one focused view instead of many competing panels. Color-coded bars carry meaning where they matter - history duration, runner pass/fail, status class. One footer hint line plus ? for the current tab's full keys (the old shortcuts rail and drifting help surfaces are gone). Env lives in its own tab and the header pill. Collections is a yazi-style file manager for the deep one-to-many chain (workspace -> collection -> folder -> request). Workspace is the header scope (F2 to switch). Three panes: parent (sibling folders, current one marked), current (a plain flat request list with a solid cursor bar), and a live preview of the highlighted request (method, URL, query, headers, last response) - the yazi signature. h/l walk up and down the tree so the panes slide, a path bar shows the full location, and a bottom status bar shows position. On a narrow terminal the panes collapse to a single breadcrumb drill-down. Premium cues from posting/atac/slumber/yazi: a segmented status line (mode + env block left, live response status/latency/size chips right; env turns red for prod), one accent hue for every focus cue, yazi's asymmetric pane ratio (thin parent, generous current + preview), filled method/status chips, and dimming tabs that do not apply (a GET greys Body/Auth). The timing waterfall is a genuine differentiator - none of those four tools has one.
